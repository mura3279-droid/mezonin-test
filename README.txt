МЕЗОНИН — УСТАНОВКА

1. Замените в GitHub app.py и requirements.txt файлами из этого комплекта.
2. В Streamlit Cloud откройте приложение -> Manage app -> Settings -> Secrets.
3. Добавьте строку (пароль придумайте самостоятельно):
   ADMIN_PASSWORD = "ваш_сложный_пароль"
4. Сохраните Secrets и перезапустите приложение.
5. Загрузите Excel, содержащий столбцы «Наименование» и «Адрес».
6. Для поиска введите ШК или откройте «Сканировать камерой» и сделайте снимок.

ВАЖНО: В этой версии Excel и статусы хранятся только в текущей сессии Streamlit.
Отметки сотрудников на других устройствах не объединяются и могут исчезнуть при перезапуске сессии.
Кабинет руководителя показывает данные только текущей сессии.
Фотография товара открывается по ссылке; если изображение отсутствует на сервере, оно не откроется.
