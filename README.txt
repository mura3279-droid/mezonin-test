МЕЗОНИН — ТЕСТОВАЯ ВЕРСИЯ

В комплекте демонстрационные 2319 строк из прежней сборки (demo_items.json).
1. Распакуйте архив.
2. Для локального запуска: pip install -r requirements.txt
3. Установите переменную окружения ADMIN_PASSWORD (свой сложный пароль).
   Либо создайте .streamlit/secrets.toml по примеру secrets.toml.example.
4. Запустите: streamlit run app.py
5. На Streamlit Cloud загрузите содержимое папки в GitHub, Main file path: app.py.
   В Streamlit Cloud -> Settings -> Secrets добавьте ADMIN_PASSWORD = "ваш_пароль".
6. Режим сотрудника доступен без пароля, администратор — по паролю.
7. В админке загрузите свой Excel, затем проверьте выбор аллеи/модуля/полки.
8. Для камеры нужен HTTPS, разрешение на камеру и браузер с BarcodeDetector
   (например Chrome Android). На iPhone возможна несовместимость — есть ручной ввод.

ВАЖНО: ЭТО ПРОТОТИП, НЕ БОЕВОЙ СЕРВИС.
- SQLite работает на одном экземпляре сервера. На Streamlit Cloud после рестарта
  файл базы может исчезнуть. Для постоянного хранения и синхронизации между
  экземплярами нужна внешняя база (например Supabase/Postgres).
- Пароль администратора проверяется сервером; никому не сообщайте пароль.
- Фотографии загружаются по адресу https://s3-pic.e-magnum.kz/item/{Код SKU}.jpg
  Если фото отсутствует, браузер может показать пустое изображение.
- Прогресс учитывает АДРЕСНЫЕ позиции (SKU + адрес), а не уникальные SKU:
  один товар на двух адресах = две задачи. Это важно для полок.
- Статусы сохраняются при обновлении Excel для совпадающих SKU+адрес+штрихкод.
- Скрипт сканирования экспериментальный; если телефон не поддерживает
  BarcodeDetector, используйте ручной ввод.

Исходное приложение не изменено. Это отдельная тестовая сборка.
